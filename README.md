**The World in a Day — Sunday 22 November 2026.** One image that sums up the day's world news, set as a newspaper front page: a Russian arms ship burning in Finnish waters after a drone strike leads, with two tankers hit in the Strait of Hormuz, a deadly boat capsize in Nigeria, the Basra power-station fire, COP31's fossil-fuel walkout threat, and India's record Test total in New Zealand. Every story was cross-checked in at least two independent sources (see `design/sources.md`); the page was designed in `design/frontpage.html` and rendered to `entry.png` (1024×1024 PNG). The program in `main.ts` copies that image byte-for-byte to the output directory and verifies the written bytes — no network, identical output on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
